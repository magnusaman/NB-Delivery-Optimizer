## Project Overview

This is a **Multi-Depot Vehicle Routing Problem (MDVRP)** system for New Brunswick delivery route optimization. It uses Google Maps Platform APIs (Places, Distance Matrix, Directions) to fetch real store locations and compute optimized delivery routes without maintaining a local road network.

**Core functionality:**
- Maps real store locations (Walmart, Dollarama, Sobeys) across New Brunswick
- Creates delivery partner networks distributed across the province
- Generates realistic customer orders with priority levels
- Optimizes delivery routes using greedy and genetic algorithms
- Exports results to QGIS-ready formats for visualization

## Important Notes

### Google Maps API
- Respect Places API quotas - bootstrap uses paging and tiling
- Distance Matrix is limited to 25×25 per request (automatically chunked)
- Requires API key with Places, Distance Matrix, and Directions APIs enabled
- Includes automatic rate limiting (`time.sleep()` between requests)

### Distance Calculations
- `_haversine_km()` provides fast approximations for greedy algorithms (lines 632-640)
- Google Maps Distance Matrix provides accurate driving distances and times
- ~1 degree latitude = 111 km, longitude scaled by cos(lat) ≈ 0.7 at NB

### Tiling Strategy
- `tiles_for_nb()` creates search grid with ~50-60km spacing (lines 54-75)
- Ensures complete coverage of NB for Places API searches
- Deduplicates results using `place_id`

### Performance Characteristics
From README benchmarks:
- Graph construction: ~30 seconds
- Distance Matrix (50×50): ~60 seconds
- Greedy optimization: <1 second
- Genetic Algorithm: ~1 second (100 generations)
- Total runtime: ~2 minutes for complete optimization
